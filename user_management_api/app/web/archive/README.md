## Archived HTML templates

This folder holds **older copies** of templates and static assets. They are **not served** by the API.

The active HTML UI lives in:

- **Templates:** `app/web/templates/`
- **Static:** `app/web/static/`
- **Docs:** [`HTML_UI.md`](../../../HTML_UI.md)

An alternate **Streamlit** UI is in [`../../../user_management_streamlit/`](../../../user_management_streamlit/) — a separate process with `BACKEND_URL` pointing at this API.
